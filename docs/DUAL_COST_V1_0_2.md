# v1.0.2｜總部／實際雙成本與歷史進價

## 既有資料不重建

本機資料庫沿用 `format=1` 和相同加密檔名，既有食材的 `price`, `packQty`, `unit`, `supplier` 繼續代表**店內實際**。原始 `purchases` 沒有 `source` 的紀錄視為 `actual`。原本銷售成本快照不改寫。

## 雙成本

- 食材新增可選的 `hqPrice`, `hqPackQty`, `hqUnit`, `hqSupplier`。
- 相同餐點配方可按 `actual` 或 `hq` 計算成本、各平台毛利；未設定任何用料的總部價時，畫面顯示「總部價格未設定」，**不能當作零成本**。
- 來源切換只是數字檢視模式，**不是 PIN 密碼鎖或帳號權限控管**。任何能開啟本機 App 且已解鎖手機的人仍可能看見完整資料。
- 進價欄位以整批為單位；比較漲跌時以每克、毫升或每件的基準單位價格換算，避免包裝縮水誤判降價。
- 總部價的基準單位類型必須與配方食材相容（例如公斤與克同類）。

## 歷史價格

在食材清單按「記錄漲價／降價」，選擇來源、生效日、總價、整包數量、單位、供應商與原因。

- 每次都**新增歷史紀錄**，附加實際輸入日期時間 `recordedAt`，不刪除歷史。
- 補登比現有最新歷史還舊的日期時，只加入紀錄，不替換當前進價。
- 來源分別保存歷史（`source=actual/hq`），無法互相覆蓋。
- 歷史頁按日期排序；差額、百分比以該來源的**上一筆歷史單位成本**比較。
- 新價格預覽會列出按現行配方用量計算的單份成本變動。**這是模擬成本影響，不會改寫任何過去銷售快照**。
- 同一天多次輸入價格，按登錄時間排序；若多筆為同日，較新的登錄代表當前版本。若要修正某筆過去紀錄，先以新備註補錄並確認差額。

## Excel 完整備份

- v1.0.2 匯出 Excel 格式 **v3**，共六張工作表。
- 「食材」原有欄位不移位，後面新增總部規格、單位、總部進價及供應商。
- 「進價紀錄」新增 `成本來源`（`actual` 或 `hq`）、`登錄時間`、`備註`。
- Excel 匯入支援原版 **v2** 和新版 **v3**。使用 v2 時沒有總部價、歷史紀錄一律解釋為實際價。
- Excel 為**未加密明文**。匯出時會含完整實際進價，需自行保護；如需加密請用既有 `.costbackup`。

## 手機驗收（正式營業數據前）

1. 用測試食材「午餐肉 12 片 $120」新增餐點，每份 1 片；店內實際成本為 $10。
2. 設定總部進價「12 片 $150」，切換兩個模式，餐點每份成本應差 $2.50。
3. 將店內價改成 12 片 $138，價格預覽應顯示 +15%、每份多 $1.50；每份實際成本 $11.50。
4. 補登舊日期「12 片 $110」，目前最新價仍為 $138；歷史頁應顯示完整生效日與登錄日。
5. 匯出 Excel v3、從 Excel 還原，檢查總部價、實際價、歷史、配方與銷售快照。
6. 用舊版 Excel v2 還原測試，確保資料與報表仍可讀取。
7. 使用同一固定簽章、增加 `versionCode` 的 APK 覆蓋 v1.0.1，確認資料完整保留。
