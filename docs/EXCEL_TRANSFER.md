# v1.0.1 Excel 完整備份／換機說明

## 匯出
1. 打開「餐飲成本管家」App →「備份」。
2. 選擇「↓ 匯出完整 Excel 試算表」。
3. 在 Android 檔案儲存介面選擇「下載」或私人儲存位置，再按「儲存」。
4. 建立的檔名預設為「餐飲成本管家-完整備份-YYYY-MM-DD.xlsx」。
5. 在 Excel／Google 試算表確認有六個工作表：「使用說明」「食材」「餐點」「配方明細」「進價紀錄」「銷售紀錄」。

## 換手機匯入
1. 將 `.xlsx` 透過 USB、受信任的裝置傳檔方式，或自行選定的私人儲存空間搬到新手機。
2. 在新手機安裝**套件 ID `tw.costkeeper.restaurant`** 相同的 App。
3. 「備份」→「↑ 從完整 Excel 還原（換手機）」。
4. 選取 `.xlsx`，App 會驗證工作表、欄位、價格／用量範圍、ID 與配方關聯。
5. 畫面列出食材、餐點、進價紀錄、銷售紀錄筆數後，確認覆蓋新手機現有資料。
6. 查看餐點成本與報表是否一致。

## 格式注意
- 這是**完整還原**，會覆蓋現在 App 的資料，不是與既有資料合併。
- **只支援本 App 匯出的格式**。從其他餐飲 Excel 匯入可先改成 CSV 食材格式，不能直接拿來當完整備份。
- 可以改價格、售價、用量等數值。不要改工作表名稱、標頭、ID、引用 ID。重新匯入後「參考」欄位會重算。
- Excel 本身是**未加密的明文**，任何取得檔案的人都能查看進價與毛利。保密優先的情境另用「匯出密碼加密備份」，同時保有 Excel 可攜性。
- `.costbackup` 的密碼需自行保管；失去密碼不可還原。App 不要求網路權限。
- 只提供簽章固定的原始碼，若編譯後 APK 尚未實測，應先在測試手機驗證流程再放入真正營業資料。
